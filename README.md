# Idham Khalid — Independent Developer

Portfolio website showcasing web products, automation systems, and infrastructure projects.
Built with Next.js, Tailwind CSS, and Framer Motion. Features a bilingual system (English/Indonesian) without relying on heavy i18n libraries.

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript

## 💻 Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000)

## 📁 Project Structure

- `src/app`: Next.js pages and layouts
- `src/components`: Reusable UI components
- `src/data`: Portfolio data (projects, site config, etc.)
- `src/i18n`: Simple translation dictionary system (en/id)
